# 親師聯絡簿 V12 正式版

## 這次不要刪除 GitHub 任何檔案
請直接把本壓縮檔解壓縮後，將裡面的檔案全部上傳到原本 GitHub 儲存庫根目錄，覆蓋同名檔案即可。

### 需要上傳
- index.html
- firebase.json
- manifest.webmanifest
- sw.js
- cover-clean.jpg
- README.md

### 不要刪除
- .github/
- .firebaserc
- firestore.rules
- 其他原有部署設定檔

## V12 功能
- 原始封面保留
- 今日聯絡簿整合今日功課、提醒、統一公告與個別聯絡
- 公告附件可直接從手機／平板選取多個檔案
- 檔案直接上傳至老師自己的 Google Drive
- 支援 PDF、Word、Excel、PowerPoint、圖片、影片、音訊與壓縮檔
- 保留既有 Google Drive／網址連結
- 個別聯絡直接選座號、姓名與家長
- 課程、學習狀況、日常表現與處理方式可複選
- 產生適合家長閱讀的客觀、防禦性文字
- 家長頁面最後只需簽閱一次
- 家長反應可轉入輔導紀錄
- Excel 匯出包含日期、時間、聯繫／晤談對象、內容與處理方式
- 強制清除舊網站快取，避免一直看到舊版

## 部署確認
上傳後等待 GitHub Actions 變成綠色，再開啟網站。登入頁與教師端都會顯示「V12」字樣，方便確認已更新。
