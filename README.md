# 親師聯絡簿 v9.3

## 本版新增
- 學生與家長資料改用 Excel（.xlsx/.xls）匯入
- 提供可下載的 Excel 匯入範本
- 個別、選取學生、全班資料皆匯出為 Excel
- Excel 內含「學生綜合資料」「出缺勤明細」「聯絡紀錄」工作表
- 統一公告與個別公告可上傳 PDF、Word、圖片
- PDF 與圖片可直接線上預覽
- DOCX 使用瀏覽器轉換為 HTML 線上預覽
- 舊式 DOC 可上傳及下載；建議轉為 DOCX 取得完整線上預覽
- 教師公告編輯區、家長預覽區與家長登入頁皆可預覽附件
- 雲端登入時附件儲存在 Firebase Storage
- 訪客模式以本機資料方式保存附件
- 保留原本封面、班級升級、學生個別頁面、家長閱覽勾選及防禦性評語

## Excel 匯入欄位
座號、姓名、學號、性別、生日、學生電話、學生地址、家長姓名、家長電話、家長地址、升學意向

## 部署提醒
除原本 Firestore 規則外，請一併部署 `storage.rules`，並確認 Firebase Storage 已啟用。
