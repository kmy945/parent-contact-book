# 親師聯絡簿 V15.4｜家長頁穩定修正版

V15 把先前確認的主要功能集中在同一版，避免再以小版本反覆修補。

## 班級與三年歷程
- 新增、修改、刪除、復原、永久刪除班級。
- 刪除班級後首頁與班級選單立即同步。
- 七年級→八年級→九年級一鍵直升。
- 九年級後畢業封存。
- 學生、家長、聯絡、簽閱、輔導／晤談、成績歷程不因升級重新建立。

## 學生／家長資料
- 手動新增、修改、移除學生。
- Excel 匯入、範本下載、Excel 匯出。
- 尚未建立班級時，可用 Excel 的「班級」欄自動建立。
- 家長資料皆可選填。
- 欄位包含家長姓名、關係、電話、Email、Line ID、緊急聯絡人與備註。

## 家長帳號管理
- Excel 匯入／新增學生後可自動建立家長帳號。
- 預設帳號依班級＋座號建立。
- 新帳號預設密碼 `Ab123456`；首次登入需修改。
- 老師可批次建立／修復帳號、重設密碼、啟用／停用、查看登入紀錄、匯出帳號清單。
- 老師不顯示家長原密碼；忘記密碼時採「重設」。
- 家長登入後可自行修改密碼與聯絡資料。
- 登入時間、登入次數與裝置資訊可供教師端查看。
- 密碼在瀏覽器資料中以 SHA-256 雜湊值儲存；舊版明碼密碼在成功登入後會轉為雜湊值。

## 今日聯絡簿與防禦性文字
- 學校公告／班級公告。
- 公告可選 Word、PDF、JPG/JPEG、PNG 多檔附件。
- 可另加多筆 Google Drive／網址連結。
- 學習與生活提醒可複選多個事件。
- 採「逐句加入」：勾選→加入一句→再勾選→再加入一句。
- 每句可換一句、修改、刪除、上下調整。
- 高風險用詞檢查，避免人格標籤、推測動機、貶抑或絕對性用詞。
- 家長最後只需勾一次「我已詳閱今日聯絡簿內容」。

## 輔導／晤談
- 可從學生事件或親師聯繫直接匯入，也可教師手動建立。
- 含日期、時間、學生、晤談對象、地點、問題類型、問題描述、晤談內容、處理方式、後續追蹤、來源。
- 問題類型含學習、生涯、家庭、人際、同儕、感情、生活適應、行為與常規、出缺勤、親師溝通、其他。
- 問題描述提供客觀、防禦性的指引詞句。

## 教師成績紀錄中心
- 預設只供教師查看。
- 老師先設定「科目＋科目權重」。
- 第一次段考、第二次段考、第三次段考、平時成績均以各科原始分數計算科目加權平均。
- 單次加權平均公式：Σ（各科成績 × 科目權重）÷ Σ科目權重。
- 再設定各次段考／平時的學期比例，計算學期參考成績。
- 科目可新增、刪除、改名、改權重。
- 各次評量比例可自行設定，並提示是否合計 100%。
- 空白分數不直接當 0 分。
- 支援正常、缺考、補考、免試狀態。
- 教師備註只在教師端顯示。
- 段考 Excel 範本下載、Excel 匯入、Excel 匯出。
- 班平均、最高、最低、及格率。
- 個人三次段考趨勢折線圖、科目雷達圖。
- 客觀成績整理文字，避免把分數解讀成人格或能力定論。
- 老師可選擇是否將某次評量分享給家長；預設不分享。
- 學生個人歷程可整合事件、出缺勤、輔導與成績。

## 公告附件的重要說明
直接上傳的 Word／PDF／圖片目前儲存在上傳該檔案的瀏覽器 IndexedDB，適合教師本機保存與預覽。
若家長需要在「不同手機／不同裝置」查看實體附件，請同時使用 Google Drive 分享連結。這是目前不升級雲端檔案後端時較安全穩定的方式。

## 舊資料承接
V15 會先讀取 `pcb_v15`；若沒有，會自動承接同一瀏覽器中的 V14 或 V13 資料。

## GitHub 更新
解壓縮後，把本包內 6 個檔案上傳到 GitHub 根目錄並覆蓋同名檔案。
保留既有 `.github/`、`.firebaserc`、`firestore.rules`、`storage.rules`、`firebase-hosting.yml` 等專案設定。


## V15.1 修正
- 修正舊版家長帳號仍保存 `123456`，但畫面顯示新版預設密碼 `Ab123456`，導致無法登入的問題。
- 舊版明碼 `123456` 與舊版 `123456` 雜湊值都會自動遷移為 `Ab123456`。
- 家長即使沒有先進入教師端，也會在登入時自動完成舊帳密遷移。
- 家長登入欄預設改為 `Ab123456`，第一次成功登入後仍必須修改密碼。
- 登入卡片改到封面右上方並降低白底不透明度，避免遮住封面中央的「親師聯絡簿」文字與主要畫面。


## V15.2 修正
- 修正舊版班級沒有 `status` 欄位時，被誤判為「未啟用」而阻擋家長登入。
- 啟動 V15.2 時，舊班級若沒有狀態會自動補成 `active`。
- 家長登入只在班級明確為 `deleted` 或 `disabled` 時阻擋。
- 班級／學年度頁新增「修復班級狀態」按鈕，方便舊資料快速修復。
- 登入卡片再縮小並往右上移，避免遮住封面主標題。


## V15.3 修正
- 修正學生帳號仍綁在舊 `classId`，導致家長登入時誤判「班級被停用或已刪除」。
- 家長登入時會先自動修復學生與目前有效班級的關聯，再進行班級狀態檢查。
- 判斷依序使用：現有 classId → 帳號前三碼班級代碼 → 學生歷程 → 舊班級資料 → 唯一有效班級。
- 教師登入時會自動檢查所有學生的班級關聯。
- 「班級／學年度」新增「修復學生班級關聯」按鈕。
- 「修復班級狀態」現在也會同步修復學生班級關聯。
- 不會刪除學生、不會重設家長密碼、不會清除聯絡簿、簽閱、輔導或成績紀錄。


## V15.4 修正
- 修正家長帳密驗證成功後，家長主畫面因資料缺漏或舊資料格式造成整頁白畫面。
- 家長登入後重新確認有效班級並修復 classId。
- 家長頁的公告、提醒、成績、簽閱資料全部加入空值容錯。
- 家長頁新增「登出」按鈕，避免載入錯誤後無法返回。
- 即使部分資料載入失敗，也會顯示「家長專區容錯頁」，不再只剩空白背景。
- 容錯頁可直接按「重新載入家長頁」。
- 增加全域 JavaScript 錯誤與非同步錯誤攔截；若家長頁發生錯誤，會顯示錯誤資訊供後續定位。
- 不重建學生、不重設密碼、不清除班級、聯絡簿、簽閱、輔導或成績資料。


## V15.6 家長端整合版
- 保留 V15.5 已經成功的家長登入驗證與容錯機制。
- 家長登入後改為與教師端一致的新式海洋系統介面，不再跳回早期簡易版。
- 家長首頁整合：班級／學生資訊、今日簽閱狀態、今日功課與提醒、學校／班級公告、附件與連結、學習與生活提醒、親師聯繫、簽閱、帳號／聯絡資料設定。
- 老師若有開放某次成績，家長端才會顯示該成績。
- 保留近期親師紀錄。
- 不修改現有班級、學生、家長帳密、輔導、簽閱與成績資料。


## V15.7｜教師 Google 雲端同步
- 「使用 Google 帳號登入」現在是真正的 Firebase Authentication Google 登入，不再只是進入本機畫面。
- Google 教師模式會將班級、學生、聯絡簿、公告、簽閱、親師聯繫、輔導／晤談、成績、家長帳號狀態與相關教師資料同步到 Firestore。
- 同一個 Google 教師帳號，在 Chrome、Samsung Internet、手機或平板登入後，會讀取同一份雲端主資料。
- 第一次啟用雲端時，系統會明確顯示「本機有幾個班級、幾位學生」，由老師確認是否把目前瀏覽器資料設成雲端主資料，避免誤把舊瀏覽器資料覆蓋正確資料。
- 之後每次儲存會先存本機，再自動排程同步到 Firebase；也可按「立即同步」。
- 「同步設定」可查看 Google 帳號、同步狀態，以及重新從雲端載入。
- 訪客體驗仍為 Local Storage 本機模式，因此不同瀏覽器的訪客資料本來就不共用。
- 公告直接上傳的 Word／PDF／圖片實體檔仍保存在上傳裝置的 IndexedDB；Google Drive／網址以及公告文字會跟著教師雲端資料同步。
