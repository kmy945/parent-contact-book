# 親師聯絡簿 V13 導師專業版

## V13 主要完成項目
- 班級可新增、修改、刪除
- 新學年一鍵升級：七→八→九，九年級後畢業封存；學生與三年歷程不中斷
- 學生／家長資料可手動新增、修改、刪除
- 學生與家長資料可 Excel 匯入；家長資料選填
- Excel 可匯出個別學生與全班完整歷程
- 公告名稱改為「學校公告／班級公告」
- 個人內容改為「學習與生活提醒」
- 勾選框與文字重新對齊並優化手機／平板點擊
- 課程分類：社會（歷史／地理／公民）、藝術（音樂／視覺藝術／表演藝術）、社團、彈性（社會／自然／國文／英文）
- 學習狀況、生活／課堂表現、處理方式均可複選
- 聯絡內容採「逐句加入」：勾選事件→加入一句→重新勾選→再加入一句，可同日累積多重狀況
- 每個事件提供多種客觀、防禦性句型，可按「換一句」
- 句子可修改、刪除、上下調整
- 送出前執行高風險用詞檢查，避免人格標籤、動機推測與貶抑詞
- 輔導／晤談可從學生事件或親師聯繫匯入，也可教師自行新增
- 輔導／晤談包含日期、時間、學生、晤談對象、地點、問題類型、問題描述、晤談內容、處理方式、後續追蹤、來源、建立教師
- 問題描述分類：學習／生涯／家庭／人際／同儕／感情／生活適應／行為與常規／出缺勤／親師溝通／其他
- 問題描述提供客觀 AI 指引詞句，一句一句加入
- 家長仍在今日聯絡簿最下方一次簽閱

## 部署
可直接把本版網站檔案覆蓋 GitHub；若 GitHub Actions Runner 不穩定，可沿用 V12.1 的手機部署工具將本 ZIP 部署至 Firebase Hosting。
