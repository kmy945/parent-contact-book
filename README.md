# 親師聯絡簿 v10 Professional

## 本版核心
- 完整保留原始封面，不裁切、不修改、不加裝飾
- 登入頁右側獨立登入面板，手機版封面在上、登入在下
- 品牌簽名：Designed by Meng（英文手寫斜體）
- 今日聯絡簿整合出缺勤、日常表現、關鍵字與個別提醒
- 出缺勤新增「準時到校」
- 請假別與請假方式皆有空白選項，代表正常到校
- 日常表現可同時多選多項
- 每一項可再多選防禦性評語
- 老師可輸入關鍵字，系統整合成家長可見文字
- 可只存教師紀錄，或正式送給該生家長
- 家長端公告與聯絡事項皆有「我已閱畢」勾選框
- 記錄閱覽時間
- 統一公告與個別公告支援 Google Drive 分享連結
- Excel 匯入、個別／選取／全班 Excel 匯出
- 班級每學年度升級，九年級畢業封存
- 家長姓名、電話、地址選填
- 升學意向：高中／高職／五專／就業／未定
