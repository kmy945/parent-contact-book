# 親師聯絡簿 v9.4－Google Drive 免費版

## 主要變更
- 完全移除 Firebase Storage，不必升級 Blaze
- 公告附件統一改用 Google Drive 分享連結
- 支援統一公告與個別公告
- 可加入多個附件連結
- 支援 PDF、Word、圖片、Excel、影片、音樂及其他檔案
- 教師發布前可預覽
- 家長預覽區可預覽
- 家長登入後可預覽與在 Google Drive 開啟
- 保留家長已閱覽勾選
- 保留 Excel 匯入與 Excel 匯出
- 保留原本封面、海洋泡泡內頁、班級升級、畢業封存及學生個別頁面

## Google Drive 使用方式
1. 在 Google Drive 找到要提供給家長的檔案。
2. 點「管理存取權」或「共用」。
3. 將一般存取權改成「知道連結的任何人」。
4. 權限選「檢視者」。
5. 複製連結，貼到親師聯絡簿公告的「Google Drive 分享連結」。
6. 可先按「預覽」，確認家長能看見後再發布。

## 注意
- 不再需要 `storage.rules`
- Firebase 仍維持 Spark 免費方案即可
- 若家長看不到檔案，通常是 Google Drive 分享權限尚未開放
