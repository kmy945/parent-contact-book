# 親師聯絡簿 V14.1｜穩定正式版

本版一次整合先前回報的主要問題，避免再以小版本反覆修補。

## 已整合
- 班級新增／修改／刪除／復原／永久刪除
- 刪除班級後首頁與班級選單立即同步，不殘留舊班級標題
- 無班級時各頁安全顯示，不再出現整頁空白
- 七→八→九原班直升，學生、家長、聯絡、簽閱、輔導／晤談歷程不中斷
- 九年級畢業封存，歷程可保留與匯出
- 學生／家長可手動新增、修改、移除
- Excel 匯入至少只需「座號、姓名」
- 尚未建立班級時，Excel 有「班級」欄（例如 706）即可自動建立班級
- 相同班級＋座號再次匯入會更新，不重複建立
- 家長資料選填：姓名、關係、電話、Email、Line ID、備註
- Excel 範本下載與目前班級學生資料匯出
- 學校公告／班級公告
- 公告可放多筆 Google Drive／網址附件
- 個人內容使用中性的「學習與生活提醒」
- 出缺勤含準時到校；請假別／請假方式空白表示到校
- 課程分類含社會（歷史／地理／公民）、藝術（音樂／視覺藝術／表演藝術）、社團、彈性（社會／自然／國文／英文）
- 學習狀況、日常／課堂表現、處理方式均可複選
- 逐句加入：勾選→產生一句→再勾選→再加入一句，同日多重狀況不覆蓋
- 每句可換句、修改、刪除、上下調整
- 防禦性文字檢查，避免人格標籤、推測動機及高風險詞
- 輔導／晤談可從學生事件、親師聯繫匯入或教師自行建立
- 輔導／晤談含日期、時間、對象、地點、問題類型、問題描述、晤談內容、處理方式、後續追蹤、來源
- 問題類型含學習／生涯／家庭／人際／同儕／感情／生活適應／行為與常規／出缺勤／親師溝通／其他
- 問題描述提供客觀指引詞句
- 家長只需最後一次勾選已詳閱
- 家長留言可轉入輔導／晤談
- Excel 完整歷程匯出
